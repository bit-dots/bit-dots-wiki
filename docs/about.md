# 关于 Bit-Dots

> **点滴成海，记录万物。**

Bit-Dots 是一个极简、纯粹的个人知识空间。它不仅是知识的归档处，更是思维的延伸与数字花园。

---

## 🎨 核心理念

我们坚持以下三个原则，并将其贯穿于站点的每一个细节：

::: info 极简 (Minimalism)
去除一切不必要的干扰（广告、社交杂音、过度装修），让内容成为唯一的焦点。
:::

::: tip 持续 (Consistency)
每一篇笔记都是一颗“点”（Dot），持续的积累最终会连点成线，汇聚成海。
:::

::: warning 纯粹 (Purity)
回归 Markdown 最原始的快感，维持文字与读者之间最深度的对话。
:::
