# 关于 Bit-Dots

> **点滴成海，记录万物。**

Bit-Dots 不仅仅是一个知识库，它是我思维的延伸，是一个纯粹、极简的灵感收集地。

---

## 🎨 核心理念

::: info 极简 (Minimalism)
去除一切不必要的干扰，让内容成为唯一的焦点。
:::

::: tip 持续 (Consistency)
每一篇笔记都是一颗“点”（Dot），持续的积累最终会连点成线，汇聚成海。
:::

::: warning 纯粹 (Purity)
没有广告，没有社交噪音，只有你和文字的深度对话。
:::
