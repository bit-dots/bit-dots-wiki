- **佑驾创新(02431.HK)：2500万元收购通图科技50%股权，加速L4自动驾驶商业化落地**
  _新时空（newtimespace.com）讯：深圳佑驾创新科技股份有限公司（佑驾创新，2431.HK）发布公告称，于2026年5月29日交易时段后，公司与卖方、认购人及目标公司订立买卖协议，有条件同意收购西安通图科技有限公司50%股权，总对价为人民币2500万元。其中，股份对价人民币2000万元将由公司向认购人配发及发行对价股份结算，现金对价人民币500万元将以现金支付予卖方。于建议收购事项完成后，目标公司将成为公司的非全资附属公司。 公告称，由于有关建议收购事项的所有适用百分比率均低于5%，该事项构成股份交易，须遵守申报及公告规定，惟获豁免遵守通函及股东批准规定。对价股份将按每股H股9.81港元的发行价配发及发行，假设公司已发行股本并无变动，将发行2,339,208股新H股，占公司于公告日期已发行股本约0.57%。该发行价较5月29日收市价每股9.890港元折让约0.81%。 目标公司成立于2019年，主要从事智能无人车运营、无人飞行器服务、地理信息服务及物流技术服务等业务。公告披露，卖方为中通快递股份有限公司，系中通快递(开曼)有限公司（纽交所及联交所双重上市）的综合联属实体；认购人ZTOWH HOLDING LIMITED为卖方指定的中通联属实体。目标公司截至2025年12月31日止年度除税后净亏损约人民币533.4万元，于该日期的未经审核资产净值约人民币151.6万元。 董事会认为，目标公司作为无人车智慧物流业务的营运平台，可对接市场上各类物流企业的物流网络与落地场景，结合集团领先的自动驾驶技术及云端智能调度系统，打造场景化无人车调度解决方案。建议收购事项是集团加速L4自动驾驶技术商业化的战略机遇，将进一步强化市场竞争力。 新时空声明： 本内容为新时空原创内容，复制、转载或以其他任何方式使用本内容，须注明来源“新时空”或“NewTimeSpace”。新时空及授权的第三方信息提供者竭力确保数据准确可靠，但不保证数据绝对正确。本內容仅供参考，不构成任何投资建议，交易风险自担。_

- **贝康医疗-B(02170.HK)：Gems取卵液获批三类证，IVF试剂全品类闭环成型**
  _新时空（newtimespace.com）讯：苏州贝康医疗股份有限公司（贝康医疗，2170.HK）发布公告称，公司Gems系列取卵液于近日获得国家药品监督管理局颁发的三类医疗器械注册证（注册证号：国械注进20263180183）。公告指出，取卵液是IVF诊疗第一道核心试剂，为后续受精、卵裂、囊胚发育提供前置保障。该产品添加硫酸庆大霉素，有效规避样本污染风险；搭载HEPES缓冲体系，可在非培养环境下稳定维持酸碱度，适配各类取卵操作场景，货架有效期长达52周。 本次获批标志着Gems系列试剂逐步完成全品类闭环布局。目前，取卵液、胚胎处理液、受精液、卵裂胚培养液、囊胚培养液、胚胎培养液六款产品已全部拿证，覆盖取卵、配子处理、受精、胚胎培养全诊疗链路。公告称，Gems系列辅助生殖用液拥有三十年IVF试剂品牌研发历史，由国际知名胚胎培养领域权威David Mortimer领衔研发，历经十三年全球多中心临床应用验证，全系产品斩获CE、FDA及TGA多重国际权威认证。 新时空声明： 本内容为新时空原创内容，复制、转载或以其他任何方式使用本内容，须注明来源“新时空”或“NewTimeSpace”。新时空及授权的第三方信息提供者竭力确保数据准确可靠，但不保证数据绝对正确。本內容仅供参考，不构成任何投资建议，交易风险自担。_
