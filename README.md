# Bit-Dots Wiki

> 极简、高颜值的个人知识 Wiki，基于 VitePress 构建。

## ✨ 特性

- 🚀 **极速响应**：基于 Vite 和 Vue，毫秒级加载体验。
- 🎨 **极简设计**：专注内容，去除冗余，保持高审美视觉。
- 📝 **Markdown 驱动**：像写文档一样写 Wiki。
- 🔍 **本地搜索**：内置全文搜索，快速定位知识点。
- ☁️ **云端部署**：集成 Cloudflare Pages，自动同步部署。

## 🛠️ 技术栈

- **框架**: [VitePress](https://vitepress.dev/)
- **部署**: [Cloudflare Pages](https://pages.cloudflare.com/)
- **版本管理**: Git + GitHub

## 🚀 本地运行

1. **安装依赖**
   ```bash
   npm install
   ```

2. **启动开发服务器**
   ```bash
   npm run docs:dev
   ```

3. **构建静态页面**
   ```bash
   npm run docs:build
   ```

## 📂 目录结构

- `docs/`: 存放所有的 Markdown 笔记和页面。
- `docs/.vitepress/`: 存放配置文件和自定义主题。
- `docs/public/`: 存放图片等静态资源。
